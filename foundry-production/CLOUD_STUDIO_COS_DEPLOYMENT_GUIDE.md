## 4. 环境搭建步骤

### 4.1 第一步: 创建Cloud Studio工作空间

#### 4.1.1 注册登录

```
1. 访问腾讯云官网
   https://cloud.tencent.com

2. 注册/登录账号
   - 支持微信扫码登录
   - 完成实名认证

3. 进入Cloud Studio
   https://cloudstudio.net
   或从控制台进入
```

#### 4.1.2 创建高性能工作空间

```
1. 点击"新建工作空间"

2. 选择工作空间类型
   ✓ 高性能工作空间

3. 选择规格
   ✓ 免费基础型
   
4. 选择模板
   ✓ PyTorch (推荐)
   或
   ✓ 空白模板 (自定义环境)

5. 配置工作空间
   - 名称: binder-design-project
   - 描述: 蛋白Binder设计系统
   
6. 点击"创建"

7. 等待启动 (约2-5分钟)
```

### 4.2 第二步: 配置开发环境

#### 4.2.1 安装Foundry

```bash
# 在Cloud Studio终端中执行

# 1. 更新pip
pip install --upgrade pip

# 2. 安装Foundry
pip install 'rc-foundry[all]'

# 3. 验证安装
python -c "import torch; print(f'PyTorch: {torch.__version__}')"
python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"
python -c "import torch; print(f'GPU: {torch.cuda.get_device_name(0)}')"
```

#### 4.2.2 下载模型权重

```bash
# 下载RFD3、MPNN、RF3模型权重
foundry install rfd3 ligandmpnn rf3

# 验证安装
foundry list
```

#### 4.2.3 安装Streamlit

```bash
# 安装Streamlit
pip install streamlit

# 安装其他依赖
pip install biotite pandas matplotlib seaborn

# 验证安装
streamlit version
```

### 4.3 第三步: 配置腾讯云COS

#### 4.3.1 创建存储桶

```
1. 进入腾讯云控制台
   https://console.cloud.tencent.com

2. 选择"对象存储COS"

3. 点击"创建存储桶"
   - 名称: binder-design-data
   - 地域: 选择离你最近的
   - 访问权限: 私有读写
   - 存储类型: 标准存储

4. 点击"创建"
```

#### 4.3.2 获取访问密钥

```
1. 进入"访问管理" → "访问密钥" → "API密钥管理"

2. 创建密钥
   - 点击"新建密钥"
   - 记录以下信息:
     * SecretId: AKIDxxxxxxxxxxxx
     * SecretKey: xxxxxxxxxxxxxxxx

3. ⚠️ 重要: 妥善保管密钥，不要泄露
```

#### 4.3.3 安装COS SDK

```bash
# 在Cloud Studio中安装
pip install cos-python-sdk-v5

# 验证安装
python -c "from qcloud_cos import CosConfig; print('COS SDK安装成功')"
```

### 4.4 第四步: 配置环境变量

```bash
# 在Cloud Studio终端中执行

# 设置COS密钥 (临时环境变量)
export COS_SECRET_ID="你的SecretId"
export COS_SECRET_KEY="你的SecretKey"
export COS_REGION="ap-beijing"  # 你的存储桶地域
export COS_BUCKET="binder-design-data-1234567890"  # 你的存储桶名称

# 添加到.bashrc (永久保存)
echo 'export COS_SECRET_ID="你的SecretId"' >> ~/.bashrc
echo 'export COS_SECRET_KEY="你的SecretKey"' >> ~/.bashrc
echo 'export COS_REGION="ap-beijing"' >> ~/.bashrc
echo 'export COS_BUCKET="binder-design-data-1234567890"' >> ~/.bashrc

# 使配置生效
source ~/.bashrc
```

## 5. 数据存储方案

### 5.1 存储桶目录结构

```
COS存储桶目录结构:

binder-design-data/
│
├── users/                      # 用户数据
│   └── user_001/
│       ├── configs/            # 配置文件
│       │   └── design_config_20250404.json
│       └── uploads/            # 上传的目标蛋白
│           └── target_protein.pdb
│
├── results/                    # 设计结果
│   └── 20250404/               # 按日期组织
│       ├── structures/         # 结构文件
│       │   ├── binder_001.cif
│       │   └── binder_002.cif
│       ├── sequences/          # 序列文件
│       │   └── sequences.fasta
│       └── metrics/            # 评估指标
│           ├── results.json
│           └── results.csv
│
├── models/                     # 模型权重 (可选)
│   ├── rfd3/
│   ├── mpnn/
│   └── rf3/
│
└── logs/                       # 操作日志
    └── operations.log
```

### 5.2 数据分类存储策略

| 数据类型 | 存储位置 | 保存时机 | 保留策略 |
|----------|----------|----------|----------|
| **用户配置** | COS /users/ | 每次设计开始 | 永久 |
| **上传文件** | COS /users/uploads/ | 用户上传时 | 永久 |
| **设计结果** | COS /results/ | 设计完成后 | 永久 |
| **临时文件** | Cloud Studio本地 | 计算过程中 | 会话结束删除 |
| **模型权重** | Cloud Studio本地 | 首次下载 | 可备份到COS |
| **操作日志** | COS /logs/ | 实时追加 | 永久 |

### 5.3 数据同步策略

```
数据同步流程:

1. 设计开始前
   └─ 从COS下载用户配置和目标蛋白

2. 设计过程中
   └─ 临时文件保存在Cloud Studio本地
   └─ 定期备份进度到COS

3. 设计完成后
   └─ 所有结果上传到COS
   └─ 清理本地临时文件

4. 用户下载
   └─ 从COS生成临时下载链接
   └─ 用户下载到本地
```
