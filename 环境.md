# ==================== 架构说明 ====================
#
# foundry 环境 (Python 3.12) - 统一运行时
# ┌──────────────────────────────────────────────┐
# │ FastAPI 后端                                  │
# │   ├── /api/upload     上传PDB                 │
# │   ├── /api/predict-hotspot  热点预测          │
# │   └── /api/run-pipeline  设计流水线           │
# │                                               │
# │ RFD3InferenceEngine  ← 直接 Python API 调用   │
# │ MPNNInferenceEngine  ← 直接 Python API 调用   │
# │ RF3InferenceEngine   ← 直接 Python API 调用   │
# │                                               │
# │ HotspotPredictor    ← 热点预测 (ML+DL)        │
# └──────────────────────────────────────────────┘
#         ↕ HTTP API
# ┌──────────────────────────────────────────────┐
# │ React 前端 (Vite + Mol* 3D可视化)             │
# │   ├── 序列查看器 + 残基选择                    │
# │   ├── 3D结构可视化 (Molstar)                   │
# │   ├── 设计参数面板                             │
# │   └── 结果展示 (RFD3/MPNN/RF3)                │
# └──────────────────────────────────────────────┘
#
# Runner 调用优先级:
# 1. foundry Python API (RFD3InferenceEngine 等) ← 最优，直接GPU推理
# 2. conda_bridge CLI (rfd3 design / mpnn / rf3 fold) ← 回退
# 3. mock 模式 ← 无GPU时演示用
#
# GPU 需求:
# - RFD3: 需要 CUDA GPU, 推荐 ≥16GB 显存
# - MPNN: 可在 CPU 运行, GPU 更快
# - RF3:  需要 CUDA GPU, 推荐 ≥16GB 显存
# - 最低配置: 1x NVIDIA A10 (24GB) 或 RTX 3090 (24GB)
# - 推荐配置: 1x NVIDIA A100 (40GB/80GB)
