## 核心功能实现

### 1. 氨基酸单字母表示

#### 三字母 → 单字母映射表

```
三字母代码 ←→ 单字母代码
─────────────────────────────────────────
ALA (Alanine)        → A    ARG (Arginine)       → R
ASN (Asparagine)     → N    ASP (Aspartate)      → D
CYS (Cysteine)       → C    GLN (Glutamine)      → Q
GLU (Glutamate)      → E    GLY (Glycine)        → G
HIS (Histidine)      → H    ILE (Isoleucine)     → I
LEU (Leucine)        → L    LYS (Lysine)         → K
MET (Methionine)     → M    PHE (Phenylalanine)  → F
PRO (Proline)        → P    SER (Serine)         → S
THR (Threonine)      → T    TRP (Tryptophan)     → W
TYR (Tyrosine)       → Y    VAL (Valine)         → V

特殊残基:
SEC (Selenocysteine) → U    PYL (Pyrrolysine)    → O
UNK (Unknown)        → X    GAP (Gap)            → -
```

#### Python 实现

```python
AA_3TO1 = {
    'ALA': 'A', 'ARG': 'R', 'ASN': 'N', 'ASP': 'D', 'CYS': 'C',
    'GLN': 'Q', 'GLU': 'E', 'GLY': 'G', 'HIS': 'H', 'ILE': 'I',
    'LEU': 'L', 'LYS': 'K', 'MET': 'M', 'PHE': 'F', 'PRO': 'P',
    'SER': 'S', 'THR': 'T', 'TRP': 'W', 'TYR': 'Y', 'VAL': 'V',
    'SEC': 'U', 'PYL': 'O', 'UNK': 'X'
}

def parse_pdb_sequences(pdb_content):
    """从 PDB 文件提取每条链的氨基酸序列"""
    chains = {}
    current_chain = None
    residues = []

    for line in pdb_content.split('\n'):
        if line.startswith('ATOM'):
            res_name = line[17:20].strip()
            chain_id = line[21]
            res_num = int(line[22:26].strip())

            if chain_id != current_chain:
                if current_chain:
                    chains[current_chain] = residues
                current_chain = chain_id
                residues = []

            if len(residues) == 0 or residues[-1][0] != res_num:
                aa = AA_3TO1.get(res_name, 'X')
                residues.append((res_num, aa))

    if current_chain and current_chain not in chains:
        chains[current_chain] = residues

    return chains
```

### 2. 序列点击 → 3D 高亮联动

#### 交互流程

```
用户点击序列中的残基 "E"（第102位）
        ↓
序列面板高亮该字母（蓝色背景）
        ↓
触发事件 → 传递 chain_id + residue_index
        ↓
Mol* 接收信号 → 在3D视图中定位并高亮对应原子
        ↓
同时底部状态栏更新: "E | Chain B | Residue 102"
```

#### 数据流架构

```
┌─────────────┐    onclick     ┌──────────────┐    select()    ┌─────────────┐
│  序列面板    │ ─────────────→ │  JavaScript  │ ────────────→ │  Mol* 核心   │
│             │                │  事件处理器   │               │             │
│ <span data- │                │              │               │ Structure-  │
│  chain="B"  │                │ 提取 chain   │               │ Selection   │
│  resnum=102 │                │ + residue    │               │ .Loci       │
│ > E </span> │                │ 信息         │               │             │
└─────────────┘                └──────────────┘               └──────┬──────┘
                                                                     ↓
                                                             ┌─────────────┐
                                                             │ 1. 高亮残基  │
                                                             │ 2. 聚焦相机  │
                                                             │ 3. 更新状态栏│
                                                             └─────────────┘
```

#### JavaScript 实现

```javascript
// 1. 序列中的每个氨基酸字母都绑定了点击事件和数据属性
<span
  class="aa hotspot"
  data-chain="B"
  data-resnum="102"
  onclick="selectResidue(this, 'B', 102)"
>
  E
</span>;

// 2. 点击时触发 Mol* 的选择 API
function selectResidue(el, chainId, resNum) {
  // 移除其他选中状态
  document
    .querySelectorAll(".aa.active")
    .forEach((e) => e.classList.remove("active"));

  // 设置当前选中
  el.classList.add("active");

  if (!viewerInstance) return;

  const plugin = viewerInstance.plugin;

  // 构建选择定位符 (Locus)
  const loci = [
    {
      "model-index": 0,
      structure: chainId, // 链标识
      "auth-asym-id": chainId, // 授权链ID
      "auth-seq-id": resNum, // 残基编号
      "label-entity-id": "1", // 实体ID
    },
  ];

  // Mol* 内部调用
  plugin.managers.interactivity.loci.selects.only({
    loci: StructureSelection.Loci(loci),
  });

  // 相机聚焦
  plugin.managers.camera.focusLoci(StructureSelection.Loci(loci));

  // 更新状态栏
  document.getElementById("statusText").innerHTML =
    '<span style="color:#1677ff;">' +
    el.textContent +
    "</span>" +
    " | Chain " +
    chainId +
    " | Residue " +
    resNum;
}
```

## 高清渲染原理

### Mol\* 渲染管线

```
PDB/CIF 文件输入
      ↓
┌─────────────────────────────────┐
│ 1. 解析层 (Parser)              │
│    - ATOM/HETATM 记录解析       │
│    - 链/残基/原子层级构建        │
│    - 二级结构计算 (DSSP)         │
└──────────────┬──────────────────┘
               ↓
┌─────────────────────────────────┐
│ 2. 几何生成层 (Geometry)        │
│                                 │
│  α-Helix → 圆柱体 + 螺旋曲线    │
│  β-Sheet → 箭头状带 + 折叠面    │
│  Loop    → 光滑样条曲线         │
│  Stick   → 圆柱体(键) + 球(原子) │
│  Sphere  → 细分球体几何          │
│                                 │
│  使用 Subdivision Surface       │
│  实现平滑曲面                    │
└──────────────┬──────────────────┘
               ↓
┌─────────────────────────────────┐
│ 3. WebGL Shader 渲染层          │
│                                 │
│  Vertex Shader:                 │
│    - MVP 矩阵变换               │
│    - 法线计算                    │
│    - 视差映射                    │
│                                 │
│  Fragment Shader:               │
│    - Blinn-Phong 光照模型       │
│    - 环境光遮蔽 (SSAO)          │
│    - 菲涅尔反射                 │
│    - 轮廓线描边                 │
│                                 │
│  Post-processing:               │
│    - MSAA/FXAA 抗锯齿          │
│    - Tone Mapping 色调映射      │
│    - Bloom 泛光效果             │
└──────────────┬──────────────────┘
               ↓
        🖼️ 高清画面输出
```

### 分子表示模式

#### Cartoon（卡通/带状）

```
特点: 显示蛋白质的二级结构骨架
适用: 整体结构展示

渲染参数:
┌────────────────────────────────────┐
│ size: 'uniform'        // 统一粗细 │
│ alpha: 1.0             // 不透明   │
│ quality: 'auto'        // 自动质量 │
│ subdivision: 4         // 曲面细分 │
│ radialSegments: 16     // 径向分段 │
└────────────────────────────────────┘

二级结构映射:
  α-Helix → 螺旋上升的带状
  β-Sheet → 扁平箭头形状
  Loop    → 光滑曲线连接
```

#### Stick（棍棒）

```
特点: 显示化学键和原子
适用: 结合位点、配体展示

渲染参数:
┌─────────────────────────────────────────┐
│ radius: 0.15            // 键的半径    │
│ multipleBond: 'offset'  // 多重键偏移  │
│ aromaticRingDisplay: true              │
└─────────────────────────────────────────┘
```

#### Sphere（球体）

```
特点: 原子球表示
适用: 关键原子、金属离子

渲染参数:
┌─────────────────────────────────────┐
│ radiusFactor: 1.0     // 半径倍率   │
│ detailLevel: 3        // 细节级别   │
└─────────────────────────────────────┘
```

### 光照模型

#### Blinn-Phong 光照公式

```
最终颜色 = 环境光 + 漫反射 + 高光

环境光 (Ambient):
  I_ambient = I_a × k_a
  // I_a: 环境光强度
  // k_a: 材质环境光系数

漫反射 (Diffuse):
  I_diffuse = I_d × k_d × max(N·L, 0)
  // I_d: 漫反射光强度
  // k_d: 材质漫反射系数
  // N: 表面法线
  // L: 光线方向

高光 (Specular):
  I_specular = I_s × k_s × pow(max(N·H, 0), n)
  // I_s: 高光强度
  // k_s: 材质高光系数
  // H: 半角向量 (光线+视线)
  // n: 高光指数 (越大越锐利)
```

### 抗锯齿技术

```
MSAA (多重采样抗锯齿):
  - 每像素多次采样
  - 硬件支持
  - 性能消耗中等

FXAA (快速近似抗锯齿):
  - 后处理图像
  - 边缘检测 + 模糊
  - 性能消耗低

SMAA (子像素形态学抗锯齿):
  - 结合 MSAA 和 FXAA 优点
  - 质量最高
  - 性能消耗较高
```

## 蛋白质 Binder 设计全流程可视化

### 概述

基于 RFDiffusion3（RFD3）、ProteinMPNN（MPNN）和 RoseTTAFold3（RF3）的蛋白质 Binder 设计全流程可视化方案，覆盖从热点残基选取到最终结构验证的完整工作流。

### 整体工作流架构

```

def render_confidence_heatmap(sequences, probabilities):
    """渲染序列置信度热图"""
    html = '<div class="sequence-heatmap">'
    
    for seq_idx, (seq, probs) in enumerate(zip(sequences, probabilities)):
        html += f'<div class="seq-row"><span class="seq-label">Seq {seq_idx+1}</span>'
        
        for pos, (aa, prob) in enumerate(zip(seq, probs)):
            # 根据概率计算颜色
            r = int(255 * (1 - prob))
            g = int(255 * prob)
            color = f"rgb({r},{g},0)"
            
            html += f'<span class="aa-cell" style="background:{color}" '
            html += f'data-pos="{pos}" data-prob="{prob:.3f}" '
            html += f'onclick="showPositionProb({pos})">{aa}</span>'
        
        html += '</div>'
    
    html += '</div>'
    return html

### Step 4: RoseTTAFold3 折叠验证与RMSD叠合分析

#### 工作流程

```
输入: MPNN设计的序列
        ↓
RoseTTAFold3 预测该序列的3D结构
        ↓
将RF3预测结构与RFD3原始主链叠合
        ↓
计算RMSD（均方根偏差）
        ↓
RMSD < 2.0 Å → 设计成功
RMSD ≥ 2.0 Å → 需要重新设计
```

#### 可视化建议

| 功能 | 实现方式 | 说明 |
|------|---------|------|
| **双结构叠合** | RFD3结构(蓝) + RF3结构(红) 叠加显示 | 直观对比两个结构的差异 |
| **RMSD热力图** | 按残基位置着色的RMSD分布 | 高RMSD区域红色，低RMSD区域蓝色 |
| **差异放大视图** | 差异区域放大 + 箭头标注偏移方向 | 放大显示结构偏差最大的区域 |
| **RMSD分布直方图** | 所有残基的RMSD分布统计 | 显示整体结构一致性 |
| **PAE矩阵热图** | RF3预测的PAE矩阵 | 评估RF3对自身预测的置信度 |
| **通过/失败指示** | 绿色✓/红色✗ 标记 | RMSD阈值判断设计是否通过 |

# RF3调用与RMSD计算
def run_rosettafold3(sequence, output_dir):
    """调用RoseTTAFold3预测结构"""
    cmd = [
        "python", "run_rf3.py",
        "--sequence", sequence,
        "--output_dir", output_dir
    ]
    
    result = subprocess.run(cmd, capture_output=True, text=True)
    return result

def calculate_rmsd(pdb1_path, pdb2_path):
    """计算两个结构的RMSD"""
    from Bio.PDB import Superimposer, PDBParser
    
    parser = PDBParser()
    struct1 = parser.get_structure("rfd3", pdb1_path)
    struct2 = parser.get_structure("rf3", pdb2_path)
    
    # 提取CA原子
    atoms1 = [atom for atom in struct1.get_atoms() if atom.get_id() == 'CA']
    atoms2 = [atom for atom in struct2.get_atoms() if atom.get_id() == 'CA']
    
    # 叠合计算RMSD
    superimposer = Superimposer()
    superimposer.set_atoms(atoms1, atoms2)
    superimposer.apply(atoms2)
    
    return superimposer.rms

def calculate_per_residue_rmsd(pdb1_path, pdb2_path):
    """计算每个残基的RMSD"""
    parser = PDBParser()
    struct1 = parser.get_structure("rfd3", pdb1_path)
    struct2 = parser.get_structure("rf3", pdb2_path)
    
    per_residue_rmsd = {}
    
    for res1, res2 in zip(struct1.get_residues(), struct2.get_residues()):
        ca1 = res1['CA'].get_coord()
        ca2 = res2['CA'].get_coord()
        
        rmsd = np.sqrt(np.sum((ca1 - ca2) ** 2))
        res_id = f"{res1.get_parent().id}:{res1.get_id()[1]}"
        per_residue_rmsd[res_id] = rmsd
    
    return per_residue_rmsd
```

    });
