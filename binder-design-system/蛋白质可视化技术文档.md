# DeepBinder 蛋白质可视化技术文档

DeepBinder 当前使用 React + Molstar 实现蛋白质结构可视化。

## 技术栈

- React 18
- Vite
- TypeScript
- Molstar
- Zustand

## 组件职责

`frontend/src/components/MolstarViewer/index.tsx`

- 初始化 Molstar viewer。
- 加载上传的 PDB 内容。
- 根据全局状态高亮靶标范围、热点残基和 hover 残基。
- 聚焦残基时只调整相机，不清空持久高亮。

`frontend/src/components/SequenceViewer/index.tsx`

- 展示按链分组的氨基酸序列。
- 支持拖拽选择靶标范围。
- 支持点击范围内残基选择热点。
- 对预测或手动选中的热点残基显示固定红点。

`frontend/src/store/useAppStore.ts`

- 保存 `selectedRange`、`selectedHotspots`、`focusedResidue`、`hoveredResidue`。
- 所有可视化组件从同一个状态源读取当前选择。

## 高亮策略

- 靶标范围：橙色，来自 `selectedRange`。
- 热点残基：红色，来自 `selectedHotspots`。
- hover 残基：蓝色，来自 `hoveredResidue`。

组件每次状态变化时按以上顺序重绘高亮。重置相机只重置视角，不清空靶标或热点状态。

## 序列热点标记

序列视图中每个残基使用固定尺寸 wrapper。热点红点通过绝对定位放在字母下方，不改变序列换行、拖拽范围或 hover 布局。
