## 1. 概述

### 1.1 什么是蛋白质Binder？

蛋白质Binder（结合蛋白）是一类能够特异性结合靶标蛋白质表面的小型蛋白质。它们在以下领域有广泛应用：

- **治疗性药物开发**：靶向疾病相关蛋白（如细胞因子、受体、酶）
- **基础研究工具**：作为抗体替代物用于蛋白质功能研究
- **生物技术**：蛋白质纯化、生物传感器、诊断试剂
- **合成生物学**：蛋白质回路设计、信号通路调控

### 1.2 DeepBinder 设计流程

DeepBinder 采用端到端的计算设计流程：

```
靶标蛋白 → 热点预测(DL) → RFD3(主链生成) → MPNN(序列设计) → RF3(结构验证) → RMSD筛选
```

| 步骤 | 工具 | 功能 | 输出 |
|------|------|------|------|
| ① 热点预测 | GAT+ESM-2 | 识别靶标表面关键残基 | Top-K热点残基列表 |
| ② 主链生成 | RFDiffusion3 | 生成Binder主链骨架 | Top-3 PDB结构 |
| ③ 序列设计 | ProteinMPNN | 设计最优氨基酸序列 | Top-3 序列 |
| ④ 结构验证 | RoseTTAFold3 | 预测结构并计算RMSD | pLDDT/PAE/RMSD |

## 2. 靶标蛋白质的选择

### 2.1 选择标准

选择合适的靶标蛋白质是Binder设计成功的关键第一步。以下是主要选择标准：

#### 2.1.1 生物学相关性

| 优先级 | 类型 | 示例 | 说明 |
|--------|------|------|------|
| ⭐⭐⭐ | 疾病驱动因子 | IL-7Rα, EGFR, PD-L1 | 直接参与疾病进程 |
| ⭐⭐⭐ | 药物靶点 | TNFα, VEGF, HER2 | 已有临床验证 |
| ⭐⭐ | 信号通路关键节点 | JAK, STAT, Ras | 调控重要通路 |
| ⭐ | 辅助研究工具 | 荧光蛋白、标签蛋白 | 用于实验技术 |

#### 2.1.2 结构可行性

- **有高质量结构**：PDB分辨率 ≤ 3.0Å，优先 ≤ 2.5Å
- **表面可及性**：靶标表面有足够大的平坦区域（>500Å²）
- **结合位点明确**：已知功能性结合位点或蛋白-蛋白相互作用界面
- **避免柔性区域**：避免选择高度柔性的无序区域作为靶点

#### 2.1.3 理化特性

| 特性 | 推荐 | 避免 |
|------|------|------|
| 分子量 | 20-80 kDa | >150 kDa（过大） |
| 等电点 | 5.0-9.0 | 极端pI值 |
| 疏水性 | 适度疏水表面 | 全亲水/全疏水表面 |
| 翻译后修饰 | 无或少修饰 | 大量糖基化位点 |

### 2.2 靶标蛋白质来源

#### 2.2.1 PDB数据库

推荐从以下数据库获取靶标结构：

- **RCSB PDB** (https://www.rcsb.org/) - 最全面的蛋白质结构数据库
- **AlphaFold DB** (https://alphafold.ebi.ac.uk/) - AlphaFold2预测结构
- **EBI PDBe** (https://www.ebi.ac.uk/pdbe/) - 欧洲蛋白质数据库

#### 2.2.2 结构选择优先级

1. **实验结构**（X-ray > Cryo-EM > NMR）
2. **高分辨率结构**（≤ 2.5Å 优先）
3. **复合物结构**（靶标-配体/抗体复合物，可参考结合模式）
4. **AlphaFold2预测**（无实验结构时使用，pLDDT > 70的区域可靠）

#### 2.2.3 典型靶标示例

| 靶标 | PDB ID | 类型 | 设计难度 |
|------|--------|------|----------|
| IL-7Rα | 3DI3 | 细胞因子受体 | ⭐⭐ |
| PD-L1 | 5J89 | 免疫检查点 | ⭐⭐ |
| EGFR | 1NQL | 酪氨酸激酶受体 | ⭐⭐⭐ |
| TNFα | 1TNF | 细胞因子 | ⭐⭐ |
| VEGF | 1VPF | 生长因子 | ⭐⭐ |
| KRAS G12C | 6OIM | GTP酶 | ⭐⭐⭐⭐ |

## 3. 结构文件准备

### 3.1 文件格式

DeepBinder 支持以下格式：

- **PDB** (.pdb) - 推荐格式，最广泛兼容
- **CIF** (.cif) - mmCIF格式，支持大分子复合物

### 3.2 结构预处理

#### 3.2.1 必要处理

1. **去除水分子**：删除HOH残基
2. **去除配体**：删除非蛋白小分子（药物、辅因子等）
3. **选择目标链**：只保留需要结合的链
4. **检查缺失残基**：确保结合位点区域完整

#### 3.2.2 推荐处理

1. **添加氢原子**：使用reduce或PDBFixer
2. **优化侧链构象**：使用Rosetta relax
3. **质子化状态**：根据pH调整His质子化

#### 3.2.3 使用PyMOL预处理示例

```python
# PyMOL预处理脚本
load target.pdb
remove resn HOH           # 去除水分子
remove not polymer        # 去除非聚合物
select chain A            # 选择目标链
remove not chain A        # 只保留链A
save target_clean.pdb
```

### 3.3 文件大小限制

- 最大文件大小：200MB
- 推荐残基数：< 1000个残基
- 超大结构建议裁剪至目标结构域

## 4. 热点残基预测

### 4.1 什么是热点残基？

热点残基（Hotspot Residues）是靶标蛋白-蛋白相互作用界面中贡献大部分结合自由能的关键残基。研究表明，界面中约20%的残基贡献了约80%的结合能。

### 4.2 预测方法

DeepBinder 提供两种方式确定热点残基：

#### 4.2.1 DL模型自动预测

- **模型**：GAT + ESM-2 图注意力网络
- **原理**：基于蛋白质序列和结构特征，预测界面残基的结合贡献
- **策略**：5折集成推理，选取Top-K（默认3个）
- **适用**：已知靶标结构，但不清楚结合位点

#### 4.2.2 手动指定

- **格式**：`链ID/残基编号`，如 `A/45, A/67, B/130`
- **适用场景**：
  - 已知功能性结合位点（文献报道）
  - 有蛋白-配体复合物结构
  - 需要靶向特定区域

### 4.3 热点残基选择策略

| 策略 | 说明 | 推荐场景 |
|------|------|----------|
| DL预测 | 自动识别界面关键残基 | 未知结合位点 |
| 文献指导 | 基于已知功能位点 | 有文献报道 |
| 复合物参考 | 参考已有复合物界面 | 有复合物结构 |
| 表面可及性 | 选择表面暴露残基 | 无先验信息 |

### 4.4 热点残基数量

- **推荐**：2-5个热点残基
- **最少**：1个（可能导致Binder方向不确定）
- **最多**：8个（过多约束可能限制设计空间）

## 5. RFD3 主链生成

### 5.1 原理

RFDiffusion3 (RFD3) 基于扩散模型，在靶标蛋白表面生成Binder主链骨架。它通过以下步骤工作：

1. **条件输入**：靶标结构 + 热点残基位置
2. **去噪扩散**：从随机噪声逐步生成主链坐标
3. **结构优化**：确保主链几何合理性

### 5.2 参数设置

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| Binder长度 | 80 | 40-150 | Binder残基数量 |
| 设计数量 | 3 | 1-10 | 生成的主链数量 |

#### 5.2.1 Binder长度选择指南

| 长度 | 适用场景 | 特点 |
|------|----------|------|
| 40-60 | 小型靶标、浅口袋 | 结构紧凑，稳定性好 |
| 60-90 | 中等靶标、平坦表面 | 平衡覆盖与稳定性 |
| 90-120 | 大型靶标、复杂界面 | 覆盖广，但可能不稳定 |
| 120-150 | 超大界面 | 实验性，需仔细验证 |

### 5.3 输出评估

- **pLDDT**：预测局部距离差异检验
  - \> 85：高置信度，主链结构可靠
  - 70-85：中等置信度，需要关注
  - < 70：低置信度，主链可能不合理

## 6. MPNN 序列设计

### 6.1 原理

ProteinMPNN 基于图神经网络，为给定的主链骨架设计最优的氨基酸序列。它考虑：

- 主链几何约束（键长、键角、二面角）
- 侧链堆积和空间位阻
- 序列与结构的兼容性

### 6.2 参数设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 序列数量 | 3 | 每个主链设计的序列数 |
| 采样温度 | 0.1 | 低温度=更保守，高温度=更多样 |

### 6.3 序列评估

- **MPNN得分**：序列与结构的兼容性分数
  - \> 0.8：高兼容性
  - 0.5-0.8：中等
  - < 0.5：可能不兼容

## 7. RF3 结构验证

### 7.1 原理

RoseTTAFold3 (RF3) 是三轨神经网络结构预测器，用于验证设计的Binder序列是否能折叠成预期结构。

### 7.2 验证指标

#### 7.2.1 RMSD（均方根偏差）

- **含义**：设计结构与预测结构的Cα原子偏差
- **阈值**：< 2.0Å 为通过
- **解读**：
  - < 1.0Å：极佳，设计结构与预测高度一致
  - 1.0-2.0Å：良好，结构基本一致
  - 2.0-3.0Å：中等，存在局部偏差
  - \> 3.0Å：较差，结构可能不稳定

#### 7.2.2 pLDDT（置信度）

- **含义**：预测结构的局部置信度
- **解读**：
  - \> 85：高置信度，结构可靠
  - 70-85：中等，局部可能不准确
  - < 70：低置信度，可能为无序区域

#### 7.2.3 PAE（预测对齐误差）

- **含义**：残基对之间的相对位置预测误差
- **解读**：
  - 低PAE（< 5Å）：残基间相对位置确定
  - 高PAE（> 15Å）：残基间相对位置不确定
  - 对角线附近低PAE：域内结构可靠

## 8. 结果评估与筛选

### 8.1 综合评分策略

推荐按以下优先级筛选：

1. **RMSD < 2.0Å**（必须通过）
2. **平均pLDDT > 80**（高置信度）
3. **MPNN得分 > 0.6**（序列-结构兼容）
4. **RFD3 pLDDT > 80**（主链质量好）

### 8.2 筛选流程

```
全部设计结果
    │
    ├─ RMSD筛选 (< 2.0Å) ──── 通过的设计
    │                              │
    │                   ├─ pLDDT排序 (> 80)
    │                   │         │
    │                   │   Top候选 ──── 实验验证
    │                   │
    │                   └─ 综合评分排序
    │
    └─ 未通过 ──── 调整参数重新设计
```

### 8.3 典型成功率

| 靶标类型 | 设计数量 | RMSD通过率 | 最终成功率 |
|----------|----------|------------|------------|
| 细胞因子 | 9-27 | 30-50% | 10-20% |
| 受体 | 9-27 | 20-40% | 5-15% |
| 酶 | 9-27 | 15-30% | 3-10% |
| 无序蛋白 | 9-27 | 5-15% | 1-5% |

## 9. 最佳实践

### 9.1 设计策略

1. **从已知界面开始**：如果有蛋白-蛋白复合物结构，优先选择已知界面残基作为热点
2. **多轮迭代**：第一轮设计不理想时，调整热点残基和Binder长度重新设计
3. **保守优先**：先使用短Binder（60-80aa），确认可行后再尝试更长的

### 9.2 参数优化

| 场景 | Binder长度 | 热点数 | 设计数 | 说明 |
|------|-----------|--------|--------|------|
| 初次尝试 | 80 | 3 (DL预测) | 3 | 快速评估可行性 |
| 优化设计 | 60-100 | 3-5 (手动) | 5-10 | 精细调整 |
| 困难靶标 | 100-150 | 5-8 | 10 | 增加约束和多样性 |

### 9.3 常见失败原因

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| RMSD全部>3Å | 热点选择不当 | 重新选择热点残基 |
| pLDDT<70 | Binder过长或过短 | 调整Binder长度 |
| MPNN得分低 | 主链几何不合理 | 增加设计数量 |
| 无设计通过 | 靶标表面不适合 | 更换靶标区域 |

### 9.4 实验验证建议

计算设计通过后，建议进行以下实验验证：

1. **基因合成**：合成Top-3候选序列
2. **蛋白表达**：大肠杆菌或哺乳动物细胞表达
3. **结合检测**：SPR/BLI测定结合亲和力
4. **结构确认**：圆二色谱验证折叠状态

## 10. 常见问题

### Q1: 上传PDB文件后无法解析？

**A:** 检查以下问题：
- 文件格式是否为标准PDB/CIF
- 是否包含ATOM记录
- 是否有缺失的链标识
- 文件编码是否为UTF-8

### Q2: DL热点预测失败？

**A:** 可能原因：
- 蛋白质过大（>1000残基），建议裁剪至目标结构域
- Biotite版本不兼容，确保 ≥ 0.38
- GPU内存不足，尝试减少输入残基数

### Q3: RFD3运行超时？

**A:** 
- 正常运行时间：10-30分钟
- 超时可能原因：GPU资源不足、模型权重未下载
- 解决：确保foundry环境正确安装，检查GPU可用性

### Q4: 所有设计RMSD都很高？

**A:** 
- 检查热点残基是否在靶标表面
- 尝试增加热点残基数量
- 调整Binder长度
- 确认靶标结构质量

### Q5: 如何选择Binder长度？

**A:** 
- 经验法则：Binder长度 ≈ 界面残基数 × 2
- 小界面（<10残基）：40-60aa
- 中等界面（10-20残基）：60-90aa
- 大界面（>20残基）：90-120aa
