# 蛋白质Binder设计系统

基于深度学习的蛋白质Binder智能设计平台，集成热点残基预测、主链生成、序列设计和结构验证全流程。

## 项目概述

本系统是一个面向蛋白质Binder设计的端到端Web应用，通过整合多个前沿深度学习模型，实现从目标蛋白结构输入到Binder设计方案输出的完整工作流。系统采用 **Top-K=3** 策略，在每个关键步骤选取最优3个候选，确保设计质量与效率的平衡。

### 核心工作流

```
目标蛋白 → 热点预测(ML+DL, Top-3) → RFDiffusion3(Top-3) → ProteinMPNN(Top-3) → RoseTTAFold3验证 → RMSD<2Å
```

## 集成模型

| 模型 | 功能 | 方法 | 说明 |
|------|------|------|------|
| **ppihotspotid** | 热点残基预测 | 机器学习 | AutoGluon集成学习，基于保守性、SASA、能量等特征 |
| **hotspot-prediction** | 热点残基预测 | 深度学习 | GAT图注意力网络 + ESM-2蛋白质语言模型，**5折集成推理** |
| **RFDiffusion3** | Binder主链生成 | 扩散模型 | 基于热点残基约束生成Binder骨架 |
| **ProteinMPNN** | 序列设计 | 图神经网络 | 根据主链骨架设计最优氨基酸序列 |
| **RoseTTAFold3** | 结构预测验证 | 三轨网络 | 预测设计序列的3D结构，计算RMSD验证 |

## 热点残基预测模块详解

### 双模型集成架构

系统采用ML+DL双模型集成策略，两个模型独立预测后加权融合：

```
输入PDB → 结构解析 → 残基特征提取
                        ├── ML分支: ppihotspotid (AutoGluon)
                        │   输入: 残基类型 + 保守性 + SASA + 能量
                        │   输出: 热点概率 (0~1)
                        │
                        ├── DL分支: hotspot-prediction (5折集成)
                        │   输入: ESM-2(1280d) + PSSM(20d) + HMM(30d) = 1330d
                        │   架构: SE-NET → GAT(3层,4头) → 注意力池化 → 分类器
                        │   推理: 5折模型取平均概率
                        │   输出: 热点概率 (0~1)
                        │
                        └── 融合: 0.5×ML + 0.5×DL → Top-K选择
```

### DL模型5折集成推理

训练时采用5折交叉验证，保存5个模型权重：

```
hotspot-prediction/models/
├── best_model_fold1.pth    ← Fold 1 权重
├── best_model_fold2.pth    ← Fold 2 权重
├── best_model_fold3.pth    ← Fold 3 权重
├── best_model_fold4.pth    ← Fold 4 权重
└── best_model_fold5.pth    ← Fold 5 权重
```

推理时加载全部5个模型，分别前向传播后取概率平均值：

```python
all_probs = []
for fold_name, model in dl_models.items():
    logits = model(graph, node_features)
    probs = torch.softmax(logits, dim=1)
    all_probs.append(probs[:, 1].numpy())
scores = np.mean(all_probs, axis=0)  # 5折集成
```

**优势**：
- 降低单模型偏差，提高预测稳定性
- 与训练时评估方式一致（5折CV）
- 自动适配：若部分权重缺失，用可用折数取平均

### ML模型 (ppihotspotid)

基于AutoGluon的集成学习模型，输入4个传统特征：

| 特征 | 说明 | 来源 |
|------|------|------|
| Ty | 残基类型 (ALA, VAL...) | PDB结构 |
| cons | 进化保守性 | Consurf/HHblits |
| sasa | 溶剂可及表面积 | DSSP/NACCESS |
| gas_e | 气相能量 | AMBER分子力场 |

模型路径：`ppihotspotid-main/AutogluonModels/ag-20230915_030535/`

### 特征构建对齐

DL模型推理时特征维度必须与训练一致：

| 特征 | 维度 | 推理时处理 |
|------|------|-----------|
| ESM-2嵌入 | 1280 | 在线提取（需加载esm2_t33_650M） |
| PSSM | 20 | 零填充（需PSI-BLAST预计算，在线推理时不可用） |
| HMM | 30 | 零填充（需HHblits预计算，在线推理时不可用） |
| **总计** | **1330** | |

> 注：PSSM和HMM特征需要PSI-BLAST/HHblits预计算，在线推理时用零填充。ESM-2特征已包含丰富的进化信息，可在一定程度上弥补PSSM/HMM的缺失。

## 功能特性

### 1. 双模型热点残基预测

- **ML模型 (ppihotspotid)**: 基于AutoGluon集成学习，利用保守性、SASA、能量等传统特征
- **DL模型 (hotspot-prediction)**: 基于GAT图注意力网络 + ESM-2蛋白质语言模型，**5折集成推理**
- **融合策略**: 两个模型结果加权平均 (0.5:0.5)，自动选取Top-K热点残基
- **备用方案**: 当模型不可用时，基于残基类型、溶剂可及性、保守性等规则的评分

### 2. RFDiffusion3 主链生成

- 基于热点残基约束生成Binder主链骨架
- 支持自定义Binder长度 (40-150 aa)
- 按pLDDT评分排序，选取Top-K最优设计
- 自动检测RFD3安装路径，未安装时使用模拟模式

### 3. ProteinMPNN 序列设计

- 根据RFD3生成的主链骨架设计氨基酸序列
- 支持调整采样温度和每设计序列数
- 按MPNN得分排序，选取Top-K最优序列
- 输出FASTA格式序列文件

### 4. RoseTTAFold3 结构验证

- 对MPNN设计的序列进行3D结构预测
- 使用Kabsch算法计算RMSD (预测结构 vs 设计主链)
- 计算每残基RMSD分布，评估局部结构一致性
- RMSD < 2.0 Å 判定为验证通过

### 5. 3D可视化

- **Mol* WebGL渲染**: 高清蛋白质结构可视化
- **多结构叠加**: 目标蛋白(绿) + RFD3 Binder(橙) + RF3预测(蓝)
- **热点残基高亮**: 红色球棍模型标注热点位置
- **RMSD分布图**: Chart.js柱状图，绿色/红色区分通过/未通过残基
- **pLDDT置信度图**: 按置信度着色 (蓝>90, 绿>70, 黄>50, 红<50)

## 系统要求

- Python 3.10+
- Streamlit 1.30+
- Biotite 0.38+
- PyTorch 2.0+
- DGL 1.1+
- Transformers 4.30+ (ESM-2模型)
- AutoGluon (ML模型)
- GPU 推荐 (ESM-2推理加速，约需3GB显存)

## 注意事项

- 未安装RFD3/MPNN/RF3时，系统自动切换到模拟模式，可完整体验工作流程
- 模拟模式下生成的结构和序列仅供演示，不代表真实生物学结果
- ESM-2模型首次加载需下载约2.5GB权重，后续自动缓存
- DL模型5折集成推理需加载5个GAT模型，内存占用约2GB
- 生产使用需安装对应模型并配置环境变量
- RMSD阈值为2.0 Å，可在侧边栏调整
