# 蛋白质Binder设计系统

基于深度学习的蛋白质Binder智能设计平台，集成热点残基预测、主链生成、序列设计和结构验证全流程。

## 项目概述

本系统是一个面向蛋白质Binder设计的端到端Web应用，通过整合多个前沿深度学习模型，实现从目标蛋白结构输入到Binder设计方案输出的完整工作流。系统采用 **Top-K=3** 策略，在每个关键步骤选取最优3个候选，确保设计质量与效率的平衡。

### 核心工作流

```
目标蛋白 → 热点预测(ML+DL, Top-3) → RFDiffusion3(Top-3) → ProteinMPNN(Top-3) → RoseTTAFold3验证 → RMSD<2Å
```

## 集成模型

| 模型 | 功能 | 方法 | 说明 |
|------|------|------|------|
| **ppihotspotid** | 热点残基预测 | 机器学习 | AutoGluon集成学习，基于保守性、SASA、能量等特征 |
| **hotspot-prediction** | 热点残基预测 | 深度学习 | GAT图注意力网络 + ESM-2蛋白质语言模型 |
| **RFDiffusion3** | Binder主链生成 | 扩散模型 | 基于热点残基约束生成Binder骨架 |
| **ProteinMPNN** | 序列设计 | 图神经网络 | 根据主链骨架设计最优氨基酸序列 |
| **RoseTTAFold3** | 结构预测验证 | 三轨网络 | 预测设计序列的3D结构，计算RMSD验证 |

## 功能特性

### 1. 双模型热点残基预测

- **ML模型 (ppihotspotid)**: 基于AutoGluon集成学习，利用保守性、SASA、能量等传统特征
- **DL模型 (hotspot-prediction)**: 基于GAT图注意力网络 + ESM-2蛋白质语言模型
- **融合策略**: 两个模型结果加权平均 (0.5:0.5)，自动选取Top-K热点残基
- **备用方案**: 当模型不可用时，基于残基类型、溶剂可及性、保守性等规则的评分

### 2. RFDiffusion3 主链生成

- 基于热点残基约束生成Binder主链骨架
- 支持自定义Binder长度 (40-150 aa)
- 按pLDDT评分排序，选取Top-K最优设计
- 自动检测RFD3安装路径，未安装时使用模拟模式

### 3. ProteinMPNN 序列设计

- 根据RFD3生成的主链骨架设计氨基酸序列
- 支持调整采样温度和每设计序列数
- 按MPNN得分排序，选取Top-K最优序列
- 输出FASTA格式序列文件

### 4. RoseTTAFold3 结构验证

- 对MPNN设计的序列进行3D结构预测
- 使用Kabsch算法计算RMSD (预测结构 vs 设计主链)
- 计算每残基RMSD分布，评估局部结构一致性
- RMSD < 2.0 Å 判定为验证通过

### 5. 3D可视化

- **Mol* WebGL渲染**: 高清蛋白质结构可视化
- **多结构叠加**: 目标蛋白(绿) + RFD3 Binder(橙) + RF3预测(蓝)
- **热点残基高亮**: 红色球棍模型标注热点位置
- **RMSD分布图**: Chart.js柱状图，绿色/红色区分通过/未通过残基
- **pLDDT置信度图**: 按置信度着色 (蓝>90, 绿>70, 黄>50, 红<50)

## 快速部署

### 方式1: 一键部署 (推荐)

```bash
cd /workspace/foundry-production/binder-design-system
bash deploy.sh
```

### 方式2: 手动部署

```bash
cd /workspace/foundry-production/binder-design-system
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
streamlit run app/binder_app.py --server.port 8501 --server.address 0.0.0.0 --server.headless true
```

### 方式3: Docker部署

```bash
cd /workspace/foundry-production/binder-design-system
docker build -t binder-system .
docker run -p 8501:8501 -v $(pwd)/outputs:/app/outputs binder-system
```

### Cloud Studio部署

1. 创建工作空间，选择PyTorch模板
2. 克隆项目: `git clone https://gitee.com/gu-qianyi0424/foundry-production.git`
3. 运行: `cd foundry-production/binder-design-system && bash deploy.sh`
4. 访问自动生成的链接 (端口8501)

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `RFD3_PATH` | 自动检测 | RFDiffusion3安装路径 |
| `MPNN_PATH` | 自动检测 | ProteinMPNN安装路径 |
| `RF3_PATH` | 自动检测 | RoseTTAFold3安装路径 |
| `HOTSPOT_ML_PATH` | 自动检测 | ML热点预测模型路径 |
| `HOTSPOT_DL_PATH` | 自动检测 | DL热点预测模型路径 |
| `STREAMLIT_PORT` | 8501 | Streamlit服务端口 |
| `STREAMLIT_ADDRESS` | 0.0.0.0 | 服务监听地址 |
| `STREAMLIT_HEADLESS` | true | 无头模式 |
| `STREAMLIT_MAX_UPLOAD_MB` | 200 | 最大上传文件大小(MB) |

## 系统要求

- Python 3.10+
- Streamlit 1.30+
- Biotite 0.38+
- PyTorch 2.0+
- GPU (可选，用于DL模型推理加速)

## 注意事项

- 未安装RFD3/MPNN/RF3时，系统自动切换到模拟模式，可完整体验工作流程
- 模拟模式下生成的结构和序列仅供演示，不代表真实生物学结果
- 生产使用需安装对应模型并配置环境变量
- RMSD阈值为2.0 Å，可在侧边栏调整
