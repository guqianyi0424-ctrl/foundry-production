# DeepBinder 项目介绍

DeepBinder 是基于深度学习的蛋白质 Binder 智能设计平台，面向靶标蛋白结构完成热点残基预测、骨架生成、序列设计和结构验证。

## 设计流程

```text
目标蛋白
  -> 热点残基预测
  -> 靶标范围选择
  -> RFD3 骨架生成
  -> MPNN 序列设计
  -> RF3 结构验证
  -> RMSD / pLDDT 评估
```

## 核心模块

- 热点残基预测：识别靶标表面可能参与结合的关键残基。
- RFD3：基于热点约束生成 Binder 主链骨架。
- MPNN：根据骨架设计 Binder 氨基酸序列。
- RF3：预测并验证设计结构。
- React + Molstar：展示序列、热点、靶标范围和 3D 结构。

## 技术架构

```text
React 前端
  - 文件上传
  - 序列视图
  - Molstar 3D 结构
  - 工作流控制

FastAPI 后端
  - API 路由
  - 服务编排
  - 模型适配
  - 实验记录

模型与工具
  - RFD3Runner
  - MPNNRunner
  - RF3Runner
  - HotspotPredictor
```

## 部署方式

DeepBinder 在云服务器上使用 conda 环境部署。

```bash
cd foundry-production/binder-design-system
conda env create -f environment.yml
conda activate deepbinder
cd frontend
npm install
npm run build
cd ../backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

需要 Nginx 反向代理时参考 `deploy-cloud.sh`。涉及系统依赖和服务配置的命令由服务器操作者手动执行。

## 系统要求

- Python 3.12
- Conda
- Node.js 20+
- PyTorch
- GPU 推荐用于真实模型推理
