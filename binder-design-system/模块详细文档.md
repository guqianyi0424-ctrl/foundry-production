# DeepBinder 蛋白质 Binder 设计系统模块文档

## 一、系统架构

DeepBinder 采用 React + FastAPI 分层架构。

```text
React UI
  -> Axios /api
FastAPI routers
  -> services
  -> adapters / repositories
  -> model runners / PostgreSQL
```

## 二、后端模块

### `backend/main.py`

创建 `DeepBinder API`，注册认证、上传、设计、实验记录、作业和监控路由。生产构建后也可以服务 `frontend/dist`。

### `backend/config/`

集中管理路径和运行时配置。模型运行环境变量使用 `DEEPBINDER_*` 前缀。

### `backend/adapters/`

封装 RFD3、MPNN、RF3、热点预测等外部模型调用。路由不直接依赖模型实现。

### `backend/services/`

承载业务编排，例如设计流水线、热点预测和实验记录服务。

### `backend/repositories/`

封装 PostgreSQL/SQLAlchemy 数据访问。

### `backend/tests/`

覆盖架构边界、配置、模型适配、服务编排、路由契约和 React 关键源码契约。

## 三、前端模块

### `frontend/src/pages/NewDesignPage.tsx`

新建设计主界面。负责文件上传、热点预测、靶标确认、RFD3/MPNN/RF3 工作流入口和结果展示。

### `frontend/src/components/SequenceViewer/index.tsx`

展示按链分组的序列，支持拖拽选择靶标范围。热点残基在对应字母下方显示固定红点。

### `frontend/src/components/MolstarViewer/index.tsx`

加载 PDB 内容并显示 3D 结构。靶标范围和热点残基使用持久高亮，hover 只作为临时反馈。

### `frontend/src/store/useAppStore.ts`

Zustand 全局状态。认证信息使用 `deepbinder_token` 与 `deepbinder_user`，并兼容迁移旧浏览器本地登录态。

## 四、部署配置

### conda 环境

`environment.yml` 定义 `deepbinder` 环境，Python 版本为 3.12。

### 前端构建

```bash
cd frontend
npm install
npm run build
```

### 后端启动

```bash
cd backend
export DEEPBINDER_DATABASE_URL='postgresql+psycopg://deepbinder:password@127.0.0.1:5432/deepbinder'
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### Nginx

云服务器使用 Nginx 服务 `frontend/dist`，并把 `/api` 代理到 `127.0.0.1:8000`。参考 `deploy-cloud.sh`。

## 五、数据库

系统强制使用 PostgreSQL。必须通过 `DEEPBINDER_DATABASE_URL` 配置连接串，主要表包括用户、实验、设计结果、流水线作业和审计日志。旧 SQLite 文件架构已停用，新部署不迁移历史 SQLite 数据。

## 六、核心工作流

1. 上传 PDB/CIF。
2. 解析链和序列。
3. 预测或手动选择热点残基。
4. 选择靶标范围。
5. 运行 RFD3 生成骨架。
6. 运行 MPNN 设计序列。
7. 运行 RF3 验证结构。
8. 保存实验记录和结果。
